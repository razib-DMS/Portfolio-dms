# Assets folder

Put your own optimized images, project screenshots, PDFs, or downloadable case-study files here.

Suggested names:
- `profile.webp`
- `seo-audit-preview.webp`
- `b2b-prospecting-preview.webp`
- `content-plan-preview.webp`

The portfolio hero currently uses `moh-mominul-islam.jpg` as the profile portrait.

If you add images to `index.html`, use meaningful `alt` text for informative images and empty alt text (`alt=""`) for purely decorative images. Compress images before uploading. Do not add client data or private prospect information without permission.
